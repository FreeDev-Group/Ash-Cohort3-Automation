# Cohort 3 Automation Feedback

This repository is dedicated to collecting professional feedback from mentees on automation testing projects completed during Cohort 3.

The main goal is to help mentees practice how to review a technical project, analyze automated tests, identify strengths and weaknesses, and communicate improvement suggestions clearly and professionally.

---

## Reviewers

The feedback will be provided by:

- Evelyne
- Dieudonné

---

## Repositories to Review

The mentees will review the automation testing repositories assigned by the mentor.

Each reviewed repository should be analyzed based on:

- Project documentation
- Installation process
- Cypress test structure
- Test execution
- Code quality
- Automation workflow
- Strengths and weaknesses
- Improvement recommendations

## Feedback Instructions

Each mentee must:

1. Review the assigned automation repository.
2. Read the README carefully.
3. Install and run the project if possible.
4. Execute the Cypress tests.
5. Analyze the test structure.
6. Identify strengths and weaknesses.
7. Suggest practical improvements.
8. Create or describe at least one GitHub Issue.
9. Submit a completed feedback file.

---

## Feedback File Naming

Each mentee must create their feedback file using the following format:

```text
feedbacks/name-feedback.md
```

Examples:

```text
feedbacks/evelyne-feedback.md
feedbacks/dieudonne-feedback.md
```

---

## Submission Rules

- Each mentee must complete the feedback individually.
- The feedback must be written professionally.
- The feedback must be specific, not general.
- Each weakness must include a suggested improvement.
- Each recommendation must be practical and clear.
- The final review decision must be justified.
- The GitHub Issue must be clear, useful, and related to the reviewed project.

---

## Mentor Notes

The mentor will evaluate each feedback based on:

- Understanding of the project
- Ability to run and analyze the tests
- Quality of technical observations
- Clarity of recommendations
- Professional communication
- Quality of the GitHub Issue created

---

## Purpose of This Exercise

This exercise helps mentees develop important software engineering skills, including:

- Reading technical documentation
- Running automated tests
- Understanding Cypress test cases
- Reviewing code quality
- Writing professional feedback
- Creating useful GitHub Issues

---

## Expected Outcome

At the end of this exercise, each mentee should be able to:

- Understand the purpose of an automation testing repository
- Run Cypress tests locally
- Review test files critically
- Identify missing or weak test scenarios
- Suggest meaningful improvements
- Write structured and professional feedback
- Create a GitHub Issue with a clear problem description and expected improvement
